## Verified how

- Headless Chromium via `tools/cdp-core.ts` (`launchOrAttachChrome`). Rendering only works
  with Chrome's bundled SwiftShader **Vulkan** ICD: the launcher now sets
  `VK_ICD_FILENAMES` to `<chrome dir>/vk_swiftshader_icd.json` and passes
  `--use-vulkan=swiftshader`. Without it the GPU process has no swap-chain shared-image
  backing, the WebGPU device is lost on the first present, and every game renders black
  (`Device LOST … "A valid external Instance reference no longer exists."`).
- Demo bundles are not in the repo; fetch them into `public/apps/` (gitignored):
  `https://bottleship.pages.dev/apps/re-volt-demo.wgb`, `…/starcraft_demo.wgb`.
- Re-Volt: fake `navigator.getGamepads()` via `Page.addScriptToEvaluateOnNewDocument`,
  boot, read `JoystickNum` (`0x6caed8`) = 1, poke `RegistrySettings.Joystick` (`0x70c9ac`)
  = 0 with `writeBytes`, then the game's own `DIJOYSTATE` (`0x6cae88`) reads lX = -127/+127
  and `rgbButtons[0]` = 0x80 as the fake pad moves. Re-Volt never auto-selects a joystick:
  Options → Controller Settings → "Select Controller".
- StarCraft: Single Player → New ID → type name → Enter → Ok reaches the mission briefing
  and map; GPU-process RSS flat (~230 MB over 2 min) instead of +85 MB/s.
- Keyboard/keypad: CDP `Input.dispatchKeyEvent` (incl. keyCode 229 + `Input.insertText`)
  and `Input.dispatchTouchEvent`; both the host SAB bitfield and the worker's `keys()`
  showed each chord in order.

## Harness verbs added (all in the DSL too)

`keys()` (pressed VKs the guest sees + consumed seq), `logRing(size)` (the ring is 50
lines by default — grow it before a boot), `logLevel(category, level)`, `readBytes(addr,
len)`, `writeBytes(addr, hex)`.

## Open / not done

- Real-device confirmation on iPad for all of the above (fullscreen exit button, keyboard
  proxy focus behaviour in Safari, keypad, Re-Volt pad after selecting it, StarCraft past
  the character screen). Everything here was verified in headless Chromium only.
- iPad + Bluetooth pad: Safari exposes a pad only after a button press, and Re-Volt
  enumerates once at startup, so press a button before launching.
- The GPU device is never re-created after a device loss; a black canvas after a GPU
  process crash stays black until reload. Consider recreating the backend on `device.lost`.
- Bundle packer once dropped every DLL from a GTA2 source folder (see the GTA2 thread);
  root cause not found — needs the original installer output the wizard was fed.
- Headless SwiftShader is slow (~1 s/frame in-game); menus are fine.

## Gotchas learned

- `pkill -f "<pattern>"` from the harness shell kills the shell itself if the pattern
  appears in its own command line; anchor on the binary path (`^/opt/pw-browsers/chromium`).
- `DPERR_*`/`DIERR_*` values: check the binary (`capstone` is pip-installable here) before
  trusting memory; the demo compared against `0x8877042E`.
- The worker log ring defaults to 50 entries; `logStats`/`logsSince` are useless for a boot
  unless `logRing` is raised first.
